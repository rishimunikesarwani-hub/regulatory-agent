The Regulatory Agent | Proposed RBI crawler

Lean-Mode ArchView Description

Proposal only. This crawler is not selected or built. The approved design still uses an external retrieval API. This view describes a possible replacement for its source collection function.

RBI publishes an RSS service for notifications. A feed lists updates and links. Establish the starting source set and check the relevant indexes as well. The feed alone cannot establish complete history or amendment coverage.

Test source access from the intended AWS runtime. Verify site rules before collection. Restrict domains, redirects, request counts, file sizes, and retries. Do not bypass access challenges.

Extract HTML and text PDFs. Scanned pages remain unsupported until OCR receives a separate scope decision. Compare content and dates. Link amendments, replacements, and withdrawals to the affected source.

Keep publication and effective dates separate. Save URLs, content hashes, exact evidence, and verification times. Incomplete discovery, failed retrieval, or uncertain coverage blocks a current assessment.

The proposed first version runs on request within the existing worker limits. Independent scheduled monitoring remains deferred. Private bank files never go to the regulator website.
